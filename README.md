# Java Array Operations

This repository contains various Java programs that demonstrate basic and intermediate array operations. 
Each file is an individual program focusing on a specific array-related task. These are great for beginners to understand array manipulation in Java.


## 🧠 Concepts Covered

- Array traversal
- Reversing arrays
- Finding min and max elements
- Checking if an array is sorted
- Counting elements
- Calculating sum and average
- Basic utility functions

## 🛠 Requirements

- Java JDK 8 or later
- Any Java IDE (e.g., IntelliJ IDEA, Eclipse, VS Code) or terminal to compile and run.
